Built for operators, not complications.

The project was born from real-world HF operation and is being built step by step, with a focus on useful controls, quick response, and a clean interface.

F

Real-time frequency

Monitor and change the frequency directly from the interface, keeping the radio and computer synchronized.

M

Modes and VFO

Control essential radio functions without having to switch between multiple windows.

D

DSP controls

A dedicated panel for features such as DNR and other controls being added to the project.

C

True CAT control

Serial communication with the radio and continuous updates of the states that matter during operation.

Q

Frequency-based logging

Information associated with a frequency can be stored and automatically recalled during operation.

+

Evolving project

New features are added as real needs arise in the shack.
