Find activity.

CAT Control is designed to make HF band operation faster and more organized. When you find activity on a frequency, mark it instantly, continue scanning the band, and jump back to your stored frequencies whenever you want — without having to remember or write them down.

Try it Explore the features
CAT Control connected to a Yaesu FTDX10

Keep track of activity without losing your place.

CAT Control was created around a simple idea: while exploring an active band, storing and returning to interesting frequencies should take only a moment.

M

Mark frequencies instantly

Found an active or interesting frequency? Mark it immediately and continue searching the band. No need to write frequencies down or try to remember them.

<>

Navigate between marked frequencies

Move quickly backward and forward through your stored frequencies, making it easy to revisit stations and activity found while scanning the band.

Q

QSO to do / QSO done

Keep frequencies marked according to their QSO status. Remember which stations you still want to work and which contacts have already been completed.

A

ADIF export

Generate an ADIF log file from your completed QSOs for easy import into QRZ.com and other logging software that supports the ADIF standard.

C

Cabrillo export for contests

Generate a Cabrillo log file for contest operation, making it easier to prepare and submit your contest log.

DSP

Direct DSP control

Adjust DNR, SHIFT and WIDTH directly from the computer interface while operating, without navigating through radio menus.

A faster way to work an active band.

Instead of stopping to write down frequencies or trying to remember where activity was found, CAT Control keeps those frequencies ready for immediate recall.

Typical operating workflow

1

Find activity
Tune normally across the band using your FTDX10.

2

Press MARK
Store the current frequency immediately and continue searching.

3

Keep exploring
Mark as many interesting frequencies as you find.

4

Jump between them
Use the navigation controls to move quickly through the stored frequencies.

5

Complete the QSO
Mark completed contacts as QSO DONE while keeping other frequencies available for QSOs still to be made.

DSP · DNR / SHIFT / WIDTH

All from one compact operating interface.

Radio control where it is useful.

CAT Control communicates directly with the Yaesu FTDX10 through its USB CAT interface. Frequency and operating information remain synchronized while frequently used controls are available directly on the computer screen.

F

VFO A frequency

Monitor the current VFO A frequency in real time and change frequency directly from CAT Control.

M

Operating modes

Select LSB, USB, CW, FM and AM directly from the interface.

D

DNR, SHIFT and WIDTH

Frequently adjusted DSP controls remain immediately accessible while you operate and move between stations.

CAT Control is under active development.

CAT Control is being developed and tested with the Yaesu FTDX10, with a focus on faster frequency management, practical QSO tracking, contest operation and direct access to useful radio controls.
